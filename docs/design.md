# Intake
MIT-licensed local-first medicine and alcohol journal. Empty initial catalog: users explicitly configure their own names, colors, units, default quantities and presets. Phone-first quiet, beautiful interface. Always-visible Today totals, one-tap logging with optional pre-entry note and backdate. Edit/delete/undo, per-item elapsed time, configurable day boundary and timezone, daily notes, explicit zero days, seven-day history, import preview and export (real .xls, JSON backup). Never infer missing logs as abstinence. No medical advice or default substances.

## Contract
One FastAPI server serves built frontend and SQLite under CONFIG_DIR (/config). Basic auth on journal /api endpoints; registration status and signup are public with first-user bootstrap, closed subsequent registration by default, and persistent abuse throttling. Generic static shell public to permit offline launch. Hash passwords using scrypt, no default credentials. Create the first account through the app; additional registration requires ALLOW_SIGNUP=true or the interactive operator CLI. Dark purple interface with readable contrast. No credentials in persistent browser storage; login form sends Basic header from memory. Local cached last profile can log offline; first use/account switches require verified online identity. Account-scoped IndexedDB data. No CDN, analytics or external runtime requests.

GET /api/me returns {id,username,settings:{timezone,day_start}}. POST /api/sync receives {operations:[{id,entity:'item'|'entry'|'day',record_id,base_version:0|integer,data:object,deleted:false|true}],cursor:integer}. Responds {results:[{id,status:'applied'|'conflict'|'invalid',record?:object,message?:string}],changes:[record],cursor:integer,has_more:boolean}. Records are {id,entity,version,deleted,data}. Each operation transaction atomically writes record, receipt and monotonic change log. Same operation ID/different payload is rejected. IDs UUIDs. Ownership comes exclusively from auth. Change pagination 500 records. Revision conflicts return server record, never overwrite. Invalid operations remain locally recoverable. Item data: name,color (#hex),unit,amount (positive numeric),presets (positive numeric array),archived (boolean),order (integer). Entry data: item_id,quantity,unit,item_name,color,occurred_at (ISO offset timestamp),timezone,note. Day data: date YYYY-MM-DD,note,zero (boolean). Settings update through PUT /api/settings {timezone,day_start} (online only), day_start integer 0..23. Quantity decimal precision retained; snapshots preserve historical units/name. Server validates all payloads, referential ownership, size limits. Archived items cannot invalidate pending historic entries.

Client local transaction writes materialized record and outbox together before acknowledging. Per-user serialized sync, ordered operations with revisions; preserve optimistic changes during remote pulls. Conflicts preserve local copy and offer keep local/use server. Request persistent storage. Do not claim cross-device freshness offline. Sync on launch/resume/reconnect/edit and bounded retries while open, closed-app best effort. Cached shell/service worker; clear-cache upgrades do not clear database. Explicit import previews JSON backups and CSV mapping with invalid/ambiguous rows flagged, no arbitrary code. XLS export includes pending local records, backend POST /api/export accepts bounded snapshot {items,entries,days}; returns real BIFF8 workbook, strings never interpreted as formulas. XLS generation uses xlwt; offline export has clear needs-server message; JSON backup works offline.

## Deployment
Docker Compose app with localhost binding by default. Networking and reverse proxies are operator-managed. /config local disk includes database, settings and consistent online backup CLI. Non-root app, writable /config, healthcheck, same-origin API, strict CSP, origin checking for mutating requests, request body limits, private no-store API responses, persistent auth throttle. Timezone/day-boundary calculation shared frontend logic with midnight/DST tests. Desktop/mobile keyboard, focus and reduced motion support.
